To fix the WordPress authentication issue, please follow these steps:

1. Open the config.json file
2. Replace the current application password with your regular WordPress account password
3. Make sure your username is correct (it should be your WordPress username, not email)

Example of correct settings:

```json
"wordpress": {
    "url": "https://suzavfx.com",
    "username": "your_wordpress_username",  // Your actual WordPress username
    "password": "your_wordpress_password",  // Your regular account password, NOT application password
    "use_application_password": false,     // Change this to false
    "api_endpoint": "/wp-json/wp/v2",
    "category": "Blog",
    "post_status": "draft",
    "future_scheduling": false
}
```

Note: WordPress XML-RPC requires your regular account password, not application passwords which are designed for the REST API.
